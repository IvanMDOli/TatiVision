# Íconos propios

- `executable.ico`: ícono del archivo `.exe`, aplicado al volver a compilar.
- `app.ico`: ícono de la ventana, diálogos y barra de tareas.
- `ui\`: íconos de controles de la interfaz en `.svg`, `.png` o `.ico`.

La compilación portable incluye el directorio `assets` automáticamente.
