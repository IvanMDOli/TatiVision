# Íconos de la interfaz

Colocá acá los íconos `.svg`, `.png` o `.ico` que se usan dentro de la
interfaz. El nombre del archivo, sin extensión, es el identificador que se
carga con `app.ui.icon_utils.load_ui_icon`, por ejemplo:

Los nombres actuales usados por la interfaz incluyen `setting`, `movie`,
`play`, `fav`, `view`, `library`, `edit`, `add` y `arrow`. El orden de
búsqueda es SVG, PNG y luego ICO.
